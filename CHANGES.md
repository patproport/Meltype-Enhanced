# Modifications from Meltype for Android

Initial public snapshot planned: 2026-10-22. This is an independent, unofficial fork of the original Android port and Meltype core, distributed under GPL-3.0-or-later. The private development history is not represented as public Git history.

- Added Zinwa Q25 SYM/right-Alt three-stage layers and editable physical-key mappings.
- Added optional single-press GRAVE language toggle while retaining Shift+Space.
- Added right-Shift-to-Ctrl shortcuts for A/C/V/X/Z/Y within the IME.
- Added shared light, dark, and system themes for the candidate bar and settings.
- Removed temporary raw key-event logging from the public source snapshot.

The original Meltype submodule remains at its recorded revision. The Pastiera JSON data, component notices, and original authorship are documented in README.md and THIRD-PARTY-NOTICES.md. The first Release version and its actual build date must be recorded when the source and APK are finalized.
